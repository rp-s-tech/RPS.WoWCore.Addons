# NobleNext

NobleNext — комплект аддонов для ролевой игры в World of Warcraft. Он объединяет
инструменты игрока, ведущего приключений (ДМ) и игрового мастера (ГМ) в одном
интерфейсе.

Клиент: **WoW 12.1.5 / Interface 120105**.

## Возможности

**Для игроков:** ролевые сообщения, трансмогрификация, оформление окна персонажа
и быстрый доступ к игровым инструментам.

**Для ДМ:** управление RP-фазами и участниками, работа со спутниками и армией,
проведение боёв и управление ролевыми сообщениями.

**Для ГМ:** инструменты создания и редактирования объектов и NPC, точки интереса,
телепорты, группы объектов, маршруты, погода и каталог команд.

Доступные разделы зависят от прав учётной записи и возможностей сервера.

## Состав

| Пакет | Назначение |
|---|---|
| [NobleNextLib](NobleNextLib/NobleNextLib.toc) | Общая библиотека интерфейса и взаимодействия с сервером |
| [NobleNext](NobleNext/NobleNext.toc) | Главное окно и инструменты игрока |
| [NobleNextDM](NobleNextDM/NobleNextDM.toc) | Инструменты ведущего приключений |
| [NobleNextGM](NobleNextGM/NobleNextGM.toc) | Инструменты игрового мастера |
| [NobleNextDB](NobleNextDB/README.md) | Справочник внешности NPC с подготовкой выбранного образа по запросу |
| [AIO_Client](AIO_Client/AIO_Client.toc) | Обмен данными между аддонами и сервером |
| [HereBeDragons](HereBeDragons/HereBeDragons.toc) | Библиотека карт и координат |
| [MogIt](MogIt/MogIt.toc) | Каталог внешностей предметов и примерочная |

NobleNextDM и NobleNextGM используют основной аддон NobleNext и общую библиотеку
NobleNextLib. Для серверных функций необходимы совместимые обработчики
NobleNext/AIO на игровом сервере.

Редактор внешности показывает исходные ID параметров и вариантов, как на сайте.
Недоступные варианты остаются в списке с пояснением. При смене расы, пола или
связанных параметров доступность пересчитывается; сервер проверяет изменение.
Справочник подключается при открытии редактора внешности. Подробные таблицы
создаются порциями только для выбранной расы и пола, затем освобождаются
при закрытии редактора или смене образа.

## Установка

Скопируйте каталоги пакетов из таблицы в папку клиента
`World of Warcraft/_retail_/Interface/AddOns`, сохранив их названия.

Пример расположения: `Interface/AddOns/NobleNext/NobleNext.toc`.

Включите аддоны в списке модификаций на экране выбора персонажа.
При добавлении новых каталогов перезапустите клиент один раз, чтобы он обнаружил
пакеты. Для обновления файлов уже известных пакетов достаточно `/reload`.
