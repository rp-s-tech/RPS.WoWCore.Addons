# Проверка текста интерфейса

`python tools/check_ui_text.py` проверяет Lua, XML и TOC собственных пакетов,
включая `NobleNextDB`. Реестр `ui-text-policy.json` задаёт допустимые диапазоны и отдельные
символы, а также замены известных проблемных значков. Всё вне разрешённого
набора считается ошибкой; новые языки добавляются в реестр явно после проверки
шрифта в клиенте. Комментарии проверяются вместе с кодом.

Разрешены печатный ASCII, русская кириллица, табуляция и переводы строк,
кавычки «», градус, тире и многоточие. Символьные иконки, математический минус,
стрелки, emoji, BOM, неразрывные/невидимые пробелы и управляющие символы
не допускаются. Для иконок следует использовать игровые текстуры, для минуса
на кнопке — ASCII `-`. Реестр не является списком всех глифов игрового шрифта.

Проверяется строгий UTF-8 и характерная повторная декодировка кириллицы через
Windows-1251. Также проверяются числовые XML-сущности и UTF-8, записанный
последовательностями Lua byte escapes. Диагностика указывает файл, строку и
код символа. Это статическая проверка: она не доказывает поддержку шрифтом
каждого разрешённого знака и не исправляет входящий текст автоматически.

Имена игроков, серверные данные и пользовательские описания не изменяются.
Сторонние AIO, MogIt, HereBeDragons и LibStub не входят в политику проекта.
Проверка запускается в GitHub Actions и перед локальной поставкой через
`addonSync.ps1` полного workspace. Требуется Python 3 без внешних зависимостей.

Тесты: `python -m unittest discover -s tools -p test_ui_text.py`.
